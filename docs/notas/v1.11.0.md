Agora o ClauGPT MCP também roda no **Linux**.

**Windows:** quem já tem o ClauGPT recebe esta versão sozinho. Para instalar do zero, baixe o `Instalar-ClauGPT-MCP.exe` abaixo.

**Linux:** um comando no terminal, sem senha de administrador:

```bash
curl -fsSL https://github.com/branding7agencia/mcp-chatgpt-n7/releases/latest/download/instalar-linux.sh | bash
```

### O que tem nesta versão
- **Instalador para Linux** (`instalar-linux.sh`): instala o Node.js se faltar, o Codex CLI, o servidor e o modelo de recorte, liga no Claude Code (e no Claude Desktop, se houver), faz o login no ChatGPT e testa. Roda de novo para reparar; `--remover` desinstala.
- **Pastas do Linux:** imagens e kits de marca na pasta de Imagens do sistema (`~/Imagens`).
- **Artes no Linux:** acha o Chrome, Edge, Chromium (inclusive snap e flatpak) ou Brave; abre também quando o servidor roda como root.
- **Encerramento limpo:** no Linux, cancelar um pedido encerra o Codex e tudo o que ele abriu.

### Arquivos
- `Instalar-ClauGPT-MCP.exe`: instalador para Windows 10 e 11.
- `Instalar-ClauGPT-MCP.cmd`: a mesma instalação, em arquivo de texto (para quando o antivírus barra o .exe).
- `instalar-linux.sh`: instalador para Linux.
- `clauGPT-mcp.json`, `clauGPT-mcp-1.11.0.tar.gz` e o `.sha256`: usados pela atualização automática.
