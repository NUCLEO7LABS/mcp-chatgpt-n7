O repositório do ClauGPT MCP mudou para **NUCLEO7LABS/mcp-chatgpt-n7**. Esta versão passa a buscar as atualizações no endereço novo. Os PCs instalados a recebem sozinhos.

**Se o ClauGPT sumiu do seu Claude:** feche o Claude, baixe o `Instalar-ClauGPT-MCP.exe` abaixo e instale por cima (no Linux, rode de novo o comando do `instalar-linux.sh`).

**Linux:**

```bash
curl -fsSL https://github.com/NUCLEO7LABS/mcp-chatgpt-n7/releases/latest/download/instalar-linux.sh | bash
```

### Arquivos
- `Instalar-ClauGPT-MCP.exe`: instalador para Windows 10 e 11.
- `Instalar-ClauGPT-MCP.cmd`: a mesma instalação, em arquivo de texto (para quando o antivírus barra o .exe).
- `instalar-linux.sh`: instalador para Linux.
- `clauGPT-mcp.json`, `clauGPT-mcp-1.11.2.tar.gz` e o `.sha256`: usados pela atualização automática.
